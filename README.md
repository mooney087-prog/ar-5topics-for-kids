# AR English P3 – Fixed Version

เวอร์ชันนี้แก้ปัญหา “กล้องเจอ Marker แต่ภาพไม่แสดง” โดย:
- เปลี่ยนรูปคำศัพท์ทั้งหมดจาก SVG เป็น PNG
- โหลดรูปไว้ล่วงหน้าใน `<a-assets>`
- ใช้ `<a-image>` และอ้างอิงรูปด้วย asset ID
- เพิ่มพื้นสีขาวด้านหลังรูป เพื่อให้เห็นภาพชัด
- ปรับการตั้งค่า AR.js ให้ตรวจจับ HIRO Marker ได้เสถียรขึ้น

## วิธีอัปโหลด
ให้อัปโหลดไฟล์ชุดใหม่นี้ทับไฟล์เดิมทั้งหมด:
- `index.html`
- โฟลเดอร์ `assets`
- `hiro-marker.png`

จากนั้น Commit changes และรอ GitHub Pages อัปเดต 1–3 นาที

## ก่อนทดสอบ
1. เปิดลิงก์ GitHub Pages ด้วย Chrome
2. กดอนุญาตกล้อง
3. รีเฟรชหน้าเว็บหนึ่งครั้ง
4. วาง HIRO Marker บนพื้นราบ
5. ให้กล้องเห็นกรอบดำครบทั้ง 4 ด้าน
6. ถือกล้องห่างประมาณ 25–40 ซม.
7. อย่าส่อง Marker จากหน้าจอเดียวกับที่เปิดเกม
